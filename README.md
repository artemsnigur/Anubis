# Heart of the Duat — вертикальный срез

3D-экшен в духе souls-like с камерой 3/4 сверху. Пробудившийся **ушебти** — фигурка из бирюзового фаянса
с золотыми прожилками — пробивается через Некрополь Дуата (загробного мира Египта) и бросает вызов
**Аммит, Пожирательнице Сердец**, в Зале Двух Истин.

Движок: **Godot 4.7** (Forward+), только статически типизированный GDScript. Все модели, анимации,
текстуры, звуки и музыка сгенерированы кодом — внешних ассетов нет (см. `CREDITS.md`).

---

## Как запустить

1. Установите Godot **4.7.x** (стандартная сборка, не .NET): <https://godotengine.org/download> или
   релизы `github.com/godotengine/godot`.
2. Откройте Godot → **Import** → выберите `project.godot` из этой папки.
   При первом открытии редактор импортирует текстуры и звуки (несколько секунд).
3. Нажмите **F5** (Run Project). Откроется титульный экран → **New Game**.

Из командной строки:

```sh
godot --path .                                            # игра
godot --path . res://scenes/levels/test_arena.tscn        # тестовая арена (манекены, алтарь)
godot --headless --path . res://tests/smoke_test.tscn     # смоук-тест
```

Прохождение среза занимает ~10–15 минут: двор → гробница → Зал колонн (+ боковая комната с наградой)
→ галерея и шорткат → второй алтарь → босс.

## Управление

Клавиатура + мышь и геймпад работают одновременно (все действия — через Input Map,
`Project Settings → Input Map`). Подсказки на экране переключаются под последнее использованное устройство.

| Действие | Клавиатура / мышь | Геймпад (Xbox-раскладка) |
|---|---|---|
| Движение | `W A S D` / стрелки | левый стик |
| Прицеливание | курсор мыши | правый стик |
| Лёгкая атака (цепочка из 3 ударов) | ЛКМ | `RB` |
| Тяжёлая атака (удерживать — заряд) | ПКМ | `RT` |
| Перекат (i-frames) | `Пробел` | `B` |
| «Око Ра» (дальняя атака, 1 заряд энергии) | `Q` | `LB` или `LT` |
| Исцеление «Анх» | `R` | `X` |
| Взаимодействие (алтарь, рычаг, святилище) | `E` | `A` |
| Захват цели / снять захват | `Tab` или СКМ | нажатие правого стика (`R3`) |
| Сменить цель | колесо мыши | D-pad ← / →, рывок правым стиком |
| Пауза / настройки | `Esc` | `Start` |
| Отладочный оверлей (FPS, состояния) | `F3` | — |
| Показать хитбоксы / хёртбоксы | `F4` | — |

## Механики

- **Бой.** Лёгкие атаки — цепочка из 3 ударов; тяжёлая заряжается до 0.8 с (урон ×1.8 и бронь от
  прерывания). Буфер ввода 0.15 с, отмена восстановления атаки перекатом, из конца переката можно сразу
  атаковать. Мягкий аим-ассист (конус ~60°) и шаг к ближайшему врагу. Хитстоп 50–90 мс (локальный —
  замирают только участники удара), тряска камеры trauma², вспышки, искры, песок, осколки фаянса,
  след клинка.
- **Ресурсы.** HP; **выносливость** (тратится на атаки и перекаты; выключается флагом
  `stamina_enabled` в `resources/balance/player_stats.tres`); **солнечная энергия** — 4 заряда
  «Ока Ра», копится ударами в ближнем бою; **Анх** — 3 заряда лечения (0.7 с, можно только медленно идти,
  удар во время питья сжигает заряд).
- **Враги.** Мумия-страж (медленная, высокая стойкость; удар сверху и захват — красная вспышка = сигнал
  перекатиться), скарабеи (рои 4–6, прыжок-укус), воин-шакал (комбо из 3 ударов, выпады, уклонения),
  жрица-кобра (плевок ядом оставляет лужу, отступает). Одновременно атакуют максимум 2 врага.
  Стойкость: сбив её, вы получаете долгое оглушение и окно повышенного урона.
- **Алтари Осириса** — чекпоинты: отдых восстанавливает HP и Анх, возрождает врагов, открывает меню
  уровней и сохраняет игру.
- **Ка** выпадает из врагов. При смерти всё Ка остаётся в **сердце** на месте гибели —
  «YOUR HEART HAS BEEN WEIGHED». Подберите его, иначе при следующей смерти оно пропадёт.
- **Уровни** за Ка: Живучесть (HP), Сила (урон хопешем), Дух (энергия и урон «Ока Ра»).
  Цена растёт с каждым уровнем.
- **Сохранение** — JSON в `user://duat_save.json` (последний алтарь, Ка, уровни, шорткаты, босс,
  награды, сердце).
- **Аммит.** Фаза 1: разворачивающийся таран (врезавшись в стену или весы — оглушена), двойной укус,
  удар хвостом, прыжок с ударной волной. Фаза 2 (< 50 % HP): рёв и красный свет, зыбучие пески,
  призыв скарабеев, ускоренные комбо, нырок под песок с ударом снизу (круг на полу).

## Настройка баланса

Все параметры — в ресурсах (`.tres`, редактируются в инспекторе Godot):

| Файл | Что внутри |
|---|---|
| `resources/balance/player_stats.tres` | HP, выносливость (вкл/выкл), скорость, перекат (длительность, i-frames, дистанция), лечение, заряд тяжёлой атаки, ссылки на атаки |
| `resources/balance/balance.tres` | буфер ввода, аим-ассист, хитстоп, тряска, лимит атакующих врагов, захват цели |
| `resources/balance/leveling.tres` | цена уровня и прибавки к характеристикам |
| `resources/attacks/*.tres` | **AttackData / EnemyAttackData**: windup / active / recovery, урон, урон по стойкости, отбрасывание, хитстоп, стамина, окна цепочки и отмены, хитбокс, телеграф, тип движения |
| `resources/enemies/*.tres` | **EnemyData**: HP, стойкость, скорости, восприятие, радиусы, список атак, награда Ка |
| `resources/animation/*.tres` | **AnimationMap**: логические имена анимаций → клипы модели |

Тайминги атак управляют и геймплеем, и анимацией: клипы-заглушки генерируются из этих чисел, а в
импортированные клипы те же тайминги вставляются как события (method tracks).

## Замена заглушек на настоящие модели и анимации

Персонажи собраны так, что качество зависит от ассетов, а не от кода. У каждого персонажа есть узел
`Visual/Rig` — сейчас это процедурная заглушка (`HeroRig`, `MummyRig`, …). Его можно заменить на
**`ModelRig`** (`scripts/rigs/model_rig.gd`) с любой импортированной моделью.

### 1. Где взять модели (CC0 и бесплатные)

- **Quaternius** (<https://quaternius.com>, CC0) — Ultimate Animated Character Pack, Animated Monster
  Pack (подойдут для мумии, шакала, существ).
- **KayKit** (<https://kaylousberg.itch.io>, CC0) — Adventurers / Skeletons, с готовыми анимациями.
- **Mixamo** (<https://www.mixamo.com>, бесплатно с аккаунтом Adobe; не CC0 — проверьте условия) —
  тысячи анимаций гуманоидов.

Обязательно проверьте лицензию на странице источника и впишите ассет в `CREDITS.md`.

### 2. Импорт с ретаргетингом (BoneMap + SkeletonProfileHumanoid)

1. Скопируйте `.glb` / `.fbx` в `assets/models/…`.
2. Дважды щёлкните файл → окно **Advanced Import Settings** → выберите узел **Skeleton3D**.
3. В разделе **Retarget → Bone Map** создайте новый `BoneMap`, **Profile = SkeletonProfileHumanoid**.
   Godot сам сопоставит кости Mixamo/Quaternius/KayKit (`mixamorig:Hips` → `Hips` и т. д.); проверьте,
   что все кружки зелёные.
4. Включите **Rest Fixer → Overwrite Axis** и **Fix Silhouette** (выравнивает позу покоя между паками).
5. Для анимаций Mixamo («Without Skin») используйте тот же BoneMap — так клипы из разных паков
   играют на одном скелете. Анимации можно сохранить в `AnimationLibrary` (**Animations → Save to File**)
   и добавить в `AnimationPlayer` модели.
6. **Reimport**.

После ретаргетинга кости называются по гуманоидному профилю: `Hips`, `Spine`, `Chest`, `Head`,
`RightHand`, `LeftHand`… — именно к ним `ModelRig` крепит сокеты (оружие, рука, голова).

### 3. Подключение к персонажу

1. Откройте `scenes/player/player.tscn`, удалите узел `Visual/Rig` (HeroRig).
2. Добавьте под `Visual` узел `Node3D` с именем **`Rig`** и скриптом `scripts/rigs/model_rig.gd`.
3. В инспекторе задайте:
   - `model_scene` — импортированная модель;
   - `model_rotation_y_deg` — 180 для glTF (модель смотрит в +Z, геймплей — в −Z);
   - `model_scale`;
   - `socket_bones` — сокет → кость (по умолчанию гуманоидные имена);
   - `weapon_scene` — сцена оружия, крепится к `RightHand`; `trail_base_offset` / `trail_tip_offset` —
     точки следа клинка;
   - `anim_map` — новый ресурс **AnimationMap**.
4. В **AnimationMap** заполните `clips`: логическое имя → имя клипа модели, например
   `idle → Idle`, `run → Run`, `light_1 → Sword_Slash_1`, `dodge → Roll`, `death → Death`.
   `fallbacks` — запасные варианты для отсутствующих клипов, `looping` — циклические клипы,
   `states` — состояния AnimationTree (можно скопировать из `hero_anim_map.tres`).
   Если несколько действий используют один клип, `ModelRig` сам создаст копии с нужными событиями.
5. Подгоните тайминги в `resources/attacks/player_*.tres` под реальные клипы: `windup` — время до
   контакта клинка, `active` — длительность удара, `recovery` — остаток. События `hitbox_on/off`,
   `footstep`, `heal_apply`, `cast_fire`, `dodge_start` будут вставлены в клипы автоматически.

Для врагов всё то же самое: замените `Visual/Rig` в `scenes/enemies/*.tscn` на `ModelRig`
(для не-гуманоидов укажите в `socket_bones` реальные имена костей: `head`, `mouth`, `weapon_tip`, `grab`).

Пример полного цикла — `tests/model_rig_test.gd`: он собирает «импортированную» модель со скелетом и
клипами в стиле Mixamo, подключает её через `ModelRig` и проверяет, что удары и события работают.

Процедурные слои (наклон в поворотах, растяжение на рывках, отдача от ударов, дрожь в хитстопе)
и белая вспышка попаданий работают поверх любой модели — они применяются к узлу `Visual` и через
`material_overlay`.

## Структура проекта

```
scenes/      main.tscn, levels/ (necropolis, test_arena), player/, enemies/, combat/, ui/
scripts/     player/ (+states), enemies/ (+states), combat/ (компоненты, данные, снаряды),
             rigs/ (заглушки и ModelRig, AnimBuilder, CharacterAnimator), world/ (кит уровня,
             алтари, ловушки, ворота, арена босса), ui/, systems/ (автозагрузки, FSM, камера),
             vfx/, levels/
resources/   attacks/, enemies/, balance/, animation/
assets/      shaders/ (world, faience, flame, venom, quicksand, trail, screen_fx …), textures/, audio/
tests/       автотесты + tests/visual (скриншоты)
tools/       генераторы ресурсов, текстур, звука, сцен врагов, проверка скриптов
```

Автозагрузки: `Settings`, `GameState`, `SaveSystem`, `AudioManager`, `HitStop`, `CameraShake`, `Vfx`,
`DebugOverlay`. Компоненты: `HealthComponent`, `HitboxComponent`, `HurtboxComponent`, `PoiseComponent`,
`StateMachine` / `State`.

## Тесты и инструменты

```sh
sh tools/check.sh                                  # все скрипты, предупреждения = ошибки
godot --headless res://tests/smoke_test.tscn       # игрок + все враги + босс, 10 с бота
godot --headless res://tests/player_motion_test.tscn
godot --headless res://tests/combat_test.tscn
godot --headless res://tests/ai_test.tscn
godot --headless res://tests/loop_test.tscn        # алтари, сердце, уровни, сохранения
godot --headless res://tests/level_test.tscn       # пути по навмешу и физический проход уровня
godot --headless res://tests/boss_test.tscn        # бой с Аммит (≈1.5 мин)
godot --headless res://tests/model_rig_test.tscn   # замена модели через ModelRig
```

- `tools/gen_audio.py` — синтез всех звуков и музыки в `assets/audio/`.
- `tools/generate_textures.gd` — шум и атлас иероглифов.
- `tools/generate_resources.gd` — **сброс** баланса к значениям по умолчанию (перезаписывает `.tres`!).
- `tools/gen_enemy_scenes.py` — сцены врагов.
- `tools/setup_project.gd` — Input Map и глобальные uniform-ы шейдеров.
- `tests/visual/*` и `tools/tour.sh` — скриншоты для визуальной проверки (окно запускается в фоне).
